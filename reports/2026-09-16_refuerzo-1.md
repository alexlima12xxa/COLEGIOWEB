## Plan original

1. **Paso 1** — Instalar fuente Poppins: descargar .woff2 variable (pesos 400–700) → `apps/web/public/fonts/poppins/PoppinsVariable.woff2` + `@font-face` en `_fonts.css`.
2. **Paso 2** — Registrar tonos: `REFUERZO1_TONOS` + `tonoRefuerzo1PorKey` en `palettes.ts`.
3. **Paso 3** — Registrar slug + contrato + ejemplo en `catalogo.ts` (slug: `refuerzo-1`, modo altura proporcional, `relacionPreview: "1600 / 645"`).
4. **Paso 4** — Crear CSS `refuerzo-1.css`: Opción B (aspect-ratio solo ≥ 64rem, cqw solo en desktop, layout apilado en móvil/tablet).
5. **Paso 5** — Crear template `BannerRefuerzo1.astro` con SVG inline themable + foto con resolveAssetUrl.
6. **Paso 6** — Registrar `BannerRefuerzo1` en `COMPONENTES` de `HomeBanner.astro`.
7. **Paso 7** — Verificación: `shared test` + `web check` + `web build` + `admin build`.

### Decisiones cerradas
- **Alineación izquierda**: todos los textos a 18.68% (incluido el título).
- **Tono**: afecta solo `fill` SVG + `color` texto CTA. Fondo del botón siempre blanco.
- **Modo de layout**: Opción B — `aspect-ratio` solo ≥ 64rem; tablet (48–64rem) con layout libre; móvil apilado.
- **Móvil (Opción A)**: foto arriba (order: -1), tarjeta SVG+texto abajo, tamaños fijos en rem.
- **SVG inline** con `preserveAspectRatio="xMidYMid slice"` + `fill: var(--banner-blue, #00209E)`.
